# 市场调研方法手册

## 适用场景

市场调研适用于以下场景：

- 进入新市场或新赛道前评估机会
- 分析行业规模、增长趋势与竞争格局
- 了解目标客户需求、痛点与决策路径
- 对标竞争对手的产品、价格、渠道与品牌
- 验证或修正业务假设（市场规模、客户意愿、定价空间）
- 为战略分析（SWOT、PESTEL、3C、五力）提供外部事实输入

## 调研流程

### 1. 定义调研问题

回答三个问题：

- **决策问题**：调研结果要支持什么决策？（进入/不进入、定价多少、优先攻哪个客群）
- **关键假设**：隐含了哪些需要验证的假设？（市场够大、客户愿意付这个价、竞品没有壁垒）
- **输出形式**：报告、打分卡、市场地图还是数据表？

### 2. 设计调研策略

根据问题类型选择调研路径：

| 问题类型 | 首选路径 | 辅助路径 |
|---|---|---|
| 市场有多大、增长多快 | 二手数据 + 行业报告 | 专家访谈验证 |
| 客户想要什么、痛点在哪 | 用户访谈 + 问卷 | 社交媒体/评论挖掘 |
| 竞争对手在做什么 | 二手数据 + 产品体验 | 渠道走访 |
| 定价是否合理 | 竞品价格映射 + 问卷 | 价格敏感度测试 |

### 3. 执行信息收集

按问题选择来源；以下是常见来源类型，不构成跨问题的固定优先级：

1. **公开权威数据**：国家统计局、央行、行业协会、白皮书、上市公司财报
2. **行业研究**：艾瑞、QuestMobile、IDC、Gartner、Forrester、36Kr、亿欧等
3. **竞品公开信息**：官网、产品文档、定价页、用户评价、招聘岗位、融资新闻
4. **用户生成内容**：社交媒体、论坛、评论区、电商评价
5. **一手调研**：问卷、访谈、焦点小组、神秘访客

### 4. 交叉验证与质量评估

对关键主张逐条检查：

- **是否适合支持这条主张？**区分原始统计、公司披露、调查结果、模型估算、评论和预测；来源名气不能替代证据质量。
- **能否追溯与复核？**记录发布机构、链接或文档、发布日期、数据期间、定义、样本和方法；尽量回到被引用的原始来源。
- **时效是否足够？**按信息变化速度和决策周期判断。报告发布日期与数据期间可能不同，两者都要记录；早期数据可用于长期趋势，但不能冒充当前水平。
- **口径是否匹配？**核对统计对象、地区、期间、币种、含税/净额、单位和计算方法。
- **可能有哪些偏差？**检查样本覆盖、估算假设、利益关系、宣传目的和幸存者偏差。

来源结果不一致时，先判断口径和范围是否相同，再保留各自数值、区间及出处。不能解释的差异标注为 `待验证`；不得仅凭固定差异百分比推断为口径错误。

### 5. 综合输出

按用户的决策需求选择输出结构；正式报告可参考 [business-reporting.md](business-reporting.md)。事实型调研不必强行给出建议，涉及决策时应明确选项、影响和建议。关键事实、数字和估算应在相邻文字或图表处注明来源、链接、发布日期与数据期间、口径和方法；二手资料尽量追溯原始来源。通常包括：

1. **调研结论摘要**：3-5 条最关键发现
2. **市场规模与趋势**：TAM、SAM、SOM、增长率、关键趋势
3. **竞争格局**：主要玩家、市场份额、定位差异
4. **客户与需求洞察**：目标客群画像、核心需求、未被满足的痛点
5. **关键假设验证结果**：哪些假设被支持、哪些被推翻、哪些待验证
6. **决策含义、方案比较或建议**（涉及决策时）
7. **信息缺口与后续调研建议**

## 搜索工具使用规范

### 何时使用搜索工具

当以下条件之一成立且宿主提供搜索工具时，启动外部搜索：

- 用户明确要求调研、查行业、看竞品、看市场
- 当前分析缺少关键外部事实（市场规模、竞品数据、行业基准）
- 涉及战略/竞争判断需要外部输入（SWOT 的机会/威胁、五力的行业结构）
- 需要验证或反驳一个关于市场的假设

用户要求搜索而宿主没有搜索工具时，说明限制并列出待核实的问题与所需来源。

### 搜索策略

1. **关键词结构化**：围绕待回答的问题形成少量可检验的搜索查询，必要时逐轮补缺口。按目标市场和可用来源选择语言，不要求机械地中英文成对：
   - 核心概念（行业/市场/产品名）
   - 限定词（规模、报告、趋势、竞争格局、市场份额）

   示例：
   ```
   "中国 SaaS CRM 市场规模 2025"
   "SaaS CRM market size 2025 forecast"
   "CRM 行业竞争格局 市场份额"
   ```

2. **评估来源适用性**：优先使用能直接支持当前主张、可追溯且方法透明的来源。政府统计、监管文件、财报和原始调查常能支持事实；咨询报告、券商研究和行业媒体可提供估算或背景，但要检查方法、引用链和潜在偏向。来源类别是检查起点，不是质量排名。

3. **按缺口迭代并停止**：先收集能回答核心决策问题的证据，再针对未解问题补充查询；当关键主张有足够支持，或新增搜索的预期价值较低时停止。搜索轮数和查询数量按问题调整，不作为硬性配额。

### 信息筛选规则

- 优先使用含发布时间、数据来源、统计口径的信息
- 单一来源的数据标注为 `单来源`，不做核心判断依据
- 对会影响结论的差异，核对统计对象、地区、期间、定义、币种、单位、方法和来源引用链；无法调和时保留各自口径和数值
- 依据变化速度评估新旧：旧资料不自动失效，需说明数据期间与当前决策的关系；未注明日期/来源的材料不得作为关键结论的唯一依据
- 预测、市场规模估算和调查结果应区分实测值与估算值，保留来源、关键假设和不确定范围

### 搜索工具纪律

- 每次搜索前明确搜索目标，不要漫无目的浏览
- 围绕关键缺口搜索；当核心发现已经交叉验证或继续搜索的边际价值较低时停止
- 搜索结果优先使用权威来源摘要，非必要不打开全文
- 搜索结束后立即整理关键发现，不把搜索结果直接堆入输出
- 若搜索结果与已有假设矛盾，优先记录矛盾，不要选择性忽略

## 市场调研方法

### 1. 市场规模估算

#### 方法一：自上而下法（Top-down）

```
TAM（总可用市场） = 目标人群总数 × 年人均消费/年客单价
SAM（可服务市场） = TAM 中符合地区、客群、场景与产品范围的部分
SOM（可获得市场） = 预测期间内可触达且可转化的 SAM 部分
```

逐个定义目标人群、期间、消费/价格口径及纳入边界。可达比例和渗透率必须有依据，并检查是否重复扣减地区、渠道、场景等限制。

适用：行业成熟、有可比的宏观或行业数据时使用。

风险：范围边界和渗透率假设容易导致高估；应以自下而上估算或可比来源交叉检查，并报告假设与区间。

#### 方法二：自下而上法（Bottom-up）

```
收入 = 可服务客户数 × 期间购买率 × 购买客户的期间订单数 × 净客单价
或
收入 = 可运营网点数 × 单网点期间销量 × 单位净收入
```

将变量定义为同一地区、同一期间和一致口径的数量；标注来源、假设及容量约束。若使用增长率，应先说明基数并计算期间末客户数，不能直接把增长率当客户数量相乘。

适用：有可参考的客户、渠道、价格或运营数据时。

优势：更贴近实际，适合早期验证。

#### 方法三：类比法（Analogy）

```
目标市场 = 相似成熟市场 × 人口/经济/渗透率调整系数
```

适用：全新市场缺乏直接数据时，参考相似市场的发展路径。

风险：类比的有效性取决于可比程度，标注关键差异。

### 2. 竞争分析调研

需要收集的信息：

- **产品与定价**：功能对比表、价格分层、免费/付费策略
- **渠道与交付**：销售模式（直销/渠道/自营/平台）、物流、服务网络
- **客户与口碑**：目标客群、客户规模、NPS、评价关键词
- **组织与资源**：团队规模、融资历史、股东背景、招聘方向
- **市场表现**：市场份额趋势、增长率、活跃用户、GMV（如公开）

信息获取渠道：

- 竞品官网、产品文档、Help Center
- 第三方评测平台（G2、Capterra、Trustpilot、大众点评端）
- 招聘网站（JD 看方向、规模、薪资）
- 融资新闻、财报（上市或披露公司）
- 用户社区、社交媒体、投诉平台

### 3. 客户与需求调研

#### 用户画像调研

至少覆盖：

- 人口属性：年龄、地域、职业、收入
- 行为特征：使用频率、使用场景、决策路径
- 需求与痛点：核心需求、未被满足的需求、切换成本
- 信息渠道：通过什么渠道了解产品、信任什么来源

#### 需求验证方法

- **问题访谈**：了解用户在什么场景下遇到什么问题，现在怎么解决
- **解决方案测试**：用户是否愿意为方案付钱/花时间
- **价格敏感度测试**：Van Westendorp 或 Gabor-Granger 法

### 4. 行业与趋势调研

重点覆盖：

- **政策环境**：监管态度、行业标准、补贴/限制政策
- **技术驱动**：关键技术成熟度、渗透率、对成本/效率的影响
- **社会变化**：消费习惯、人口结构、工作方式的变化
- **资本流向**：赛道融资总额、头部项目、估值变化

来源举例（中国）：

- 国家统计局、工信部、商务部
- 36Kr、晚点、虎嗅、甲子光年、亿欧
- 上市公司财报、招股书
- 券商行业研报（东方财富、Wind）
- 咨询公司报告（McKinsey、BCG、Bain、Deloitte、PwC、KPMG）

来源举例（国际）：

- World Bank、IMF、OECD、UN
- Gartner、IDC、Forrester、Frost & Sullivan
- Crunchbase、PitchBook、CB Insights
- SEC filings (10-K, 10-Q)、annual reports

## 输出质量检查清单

输出前逐项检查：

- [ ] 调研问题是否明确对应一个决策场景
- [ ] 每条关键发现都有来源标注（来源 + 时间）
- [ ] 关键事实附近可定位来源、链接、发布日期/数据期间和口径
- [ ] 未验证的关键假设已标注 `待验证` 或 `假设`
- [ ] 分歧数据已标注不同口径和出处
- [ ] 市场规模的统计口径已说明（TAM/SAM/SOM、时间段、包含范围）
- [ ] 竞品信息标注了收集时间和可靠程度
- [ ] 没有把搜索结果直接堆砌到输出中，而是做了综合提炼
- [ ] 调研结论直接回答了起始的决策问题
- [ ] 涉及决策时，呈现决策含义、方案权衡或建议；事实型调研明确保持中立

## 与现有分析框架的关系

市场调研为其他分析框架提供外部输入：

- `SWOT`：调研结果为机会和威胁提供事实依据
- `PESTEL`：调研覆盖政策、经济、社会、技术维度
- `3C`：调研覆盖客户和竞争对手维度
- `五力`：调研覆盖行业结构、替代品、新进入者
- `STP`：调研覆盖市场细分、客户画像和定位依据
- `4P`：调研覆盖竞品定价、渠道和促销策略

市场调研本身不替代上述框架，而是在框架需要外部数据时提供输入。调研结果进入分析流程后，仍需遵守 `SKILL.md` 的分析纪律。
